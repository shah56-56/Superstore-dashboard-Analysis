Excel Sales Analysis - Superstore

 Project Aim:
   The goal of this project is to analyze the performance of products, category, subcategory across different regions and different segments. To also identify the patterns and trends over months, years, days.


 Dataset:
- <a href="https://github.com/shah56-56/Superstore-Dashboard-/blob/main/sales%20-analysis.xlsx">Dataset</a>
  - Sales by Category and Segment
- Orders by Segment and Ship Mode

 Charts: Sample Superstore Dataset
- Columns: Order Date, Region, Segment, Category, Sales, Profit, Quantity, Ship Mode

 Data Cleaning:
- Removed duplicates
- Checked missing values
- Formatted Sales and Profit
- Created Month and Weekday columns


 Pivot Tables:
- Sales by Region
- Profit by Month
- Sales by Weekday
- Top 10 Orders
- Sales by Category and Region
- Clustered Column Chart
- Stacked Column Chart
- Line Chart
- Bar Chart


  Dashboard:    
     https://github.com/shah56-56/Superstore-dashboard-Analysis/blob/main/Screenshot.png

  
   Results:
- West Region generated the highest sales.
- Technology category had the highest sales.
- Consumer segment placed the most orders.
- Standard Class was the most used shipping mode.

 Project Insights:
- Focus on Technology products.
- Improve sales in the South region.
- Promote high-profit categories.
- Optimize shipping methods.
